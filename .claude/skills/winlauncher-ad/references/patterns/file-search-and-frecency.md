# ファイル検索・frecency・検索フォルダ詳細設定

→ 詳細: [file-search-and-frecency.md](../../../../../docs/internal-design/file-search-and-frecency.md)

- `search_files` は候補（`FileEntry`。`icon`は常に`None`）と検索打ち切り判定（`SearchOutcome.truncated`）だけを返す。Shellアイコン取得は行わない（表示範囲優先取得は別モジュール）。後続の検索フォルダへファイルシステムアクセスして`truncated`の精度を上げようとしない（既存契約に反する）。 → 詳細: [file-search-and-frecency.md](../../../../../docs/internal-design/file-search-and-frecency.md#search-logic)、Shellアイコン取得の詳細は[shell-icon-loading.md](../../../../../docs/internal-design/shell-icon-loading.md)
- 通常検索は強制中断せず、Rust側の共有世代番号（`Generation`／`SEARCH_GENERATION`）を処理境界ごとに確認する協調的キャンセルで打ち切る。新しく「重い走査を打ち切り可能にしたい」コマンドを追加する場合はこの`Generation`パターンを再利用し、個別のフラグ・チャネルを新設しない。 → 詳細: [file-search-and-frecency.md](../../../../../docs/internal-design/file-search-and-frecency.md#search-cooperative-cancellation)
- 通常検索の再実行中は「検索中…」行を出さず直前結果を保持し続け、最新世代確定時に一括置換する。検索欄のスピナーは`searchBusyRef`が100ms継続した場合だけ表示する（ちらつき防止の表示判定であり、検索処理自体のタイムアウトではない）。 → 詳細: [file-search-and-frecency.md](../../../../../docs/internal-design/file-search-and-frecency.md#search-continuity-and-spinner)
- 拡張子フィルタリングを持つ設定を新設する場合、ブラックリスト用・ホワイトリスト用は必ず独立フィールドとして持たせる（共有フィールドにしない。モード切替で入力内容が意図せず流用される事故を防ぐため）。 → 詳細: [file-search-and-frecency.md](../../../../../docs/internal-design/file-search-and-frecency.md#folder-detail-settings)
- frecencyスコアは `count * decay(lastUsed)`。この仕組み（decay係数・二次キー）はプレフィックスコマンド候補（`docs/internal-design/calc-and-prefix-commands.md`）でもキーを `path` から `keyword` に変えて再利用する。 → 詳細: [file-search-and-frecency.md](../../../../../docs/internal-design/file-search-and-frecency.md#frecency)
- 検索フォルダ情報ダイアログ・除外ファイル一覧ダイアログは、通常検索とは独立した世代管理（`FOLDER_INFO_GENERATION`）・最大20階層走査・キャッシュなしで動く。除外ファイル一覧は情報ダイアログ取得済みデータを再利用し追加走査しない。新しいサブモーダルを重ねる場合、開閉状態は呼び出し元が持ちEscape優先順位チェーンへ組み込む。 → 詳細: [file-search-and-frecency.md](../../../../../docs/internal-design/file-search-and-frecency.md#folder-info-dialog)、[file-search-and-frecency.md](../../../../../docs/internal-design/file-search-and-frecency.md#excluded-files-modal)
- 検索フォルダ一覧の並び替えは専用ドラッグハンドルだけをドラッグ起点にする（行全体draggableにしない）。ピン止め・お気に入り編集ビューの「行全体draggable」パターンとは意図的に異なる。 → 詳細: [file-search-and-frecency.md](../../../../../docs/internal-design/file-search-and-frecency.md#search-folder-reordering)
- ファイル起動は `ShellExecuteW` を直接呼ぶ（`cmd /C start` はコマンドインジェクションのリスクがあるため使わない）。 → 詳細: [file-search-and-frecency.md](../../../../../docs/internal-design/file-search-and-frecency.md#file-launch)
- 拡張子タグ編集 UI は `ExtensionFilterEditor.tsx` を再利用し、個別実装を増やさない。 → 詳細: [file-search-and-frecency.md](../../../../../docs/internal-design/file-search-and-frecency.md#extension-filter-editor-extraction)
