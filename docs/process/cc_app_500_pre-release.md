# 500_リリース前作業 — CC実施要領

工程定義表全体は [WORKFLOW.md](../../WORKFLOW.md) を参照。本ファイルは 500_リリース前作業 工程における CC（Claude Code）自身の実施要領のみを扱う。

## INPUT

- CA からのドキュメント反映依頼

## 手順

1. `DESIGN_LOG.md` の該当トピックの結論を、`CLAUDE.md`「設計原則ダイジェスト」節（再利用可能な原則のみ）と対応する `docs/design/*.md`（現状仕様・経緯）へ正式反映する
2. `CLAUDE.md`「ダイジェストと detail doc のアンカー同期ルール」に従い、アンカー ID・ポインタの対応関係を崩さないよう更新する
3. `README.md` へ反映する（必要時のみ。`CLAUDE.md`「ドキュメント言語方針」節の通り README.md は英語のみで統一する。反映不要な変更の場合はこのステップをスキップする）
4. 反映確認
5. 反映が完了したトピックの見出しのみ `DESIGN_LOG.md` から削除する。他の未反映トピックが残っている場合は、それらを巻き込んで削除しない（トピック単位の部分クリア）
6. 依存関係の最終確認（必要な場合のみ）

## DESIGN_LOG.md クリア漏れの機械的確認

新しいセッションでこの工程に着手する前に、まず `DESIGN_LOG.md` を開いて見出しが残っていないか確認する。見出しが残っている場合は、それが「反映済みだが削除し忘れているだけ」なのか「まだ未反映」なのかを、`CLAUDE.md`・対応する `docs/design/*.md` の実際の記載と突き合わせて判定する。**反映済みと確認できた場合のみ削除する**。存在するというだけで自動的に削除してよいわけではない。

## OUTPUT

- 更新済み `CLAUDE.md` / `docs/design/*.md`
- 更新済み `README.md`（該当時）
